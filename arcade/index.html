Put a game on your home screen

Each game installs as its own app. Open the game first, then:
  1. iPhone / iPad (Safari): tap Share, then Add to Home Screen.
  2. Android (Chrome): tap ⋮, then Install app or Add to Home screen.
After the first open, the games run offline.
